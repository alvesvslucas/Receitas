# Receitas da Tia Jurema

Site de receitas desenvolvido em um desafio da faculdade Estácio no curso de Desenvolvimento Full Stack, conforme a documentação original.

## Tecnologias e recursos

- HTML, CSS e Bootstrap 4.4.1 carregado por CDN.
- Página inicial de apresentação.
- Página com três receitas, ingredientes, imagens e preparo.
- Formulário de cadastro demonstrativo.
- Navegação entre as três páginas.

## Como visualizar

```bash
git clone https://github.com/alvesvslucas/Receitas.git
cd Receitas
```

Abra `index.html` em um navegador. A estilização do Bootstrap depende de conexão com a internet.

## Estrutura

- `index.html`: página inicial.
- `receitas.html`: catálogo de receitas.
- `cadastro.html`: formulário.
- `formatos.css`, `receitas.css` e `style.css`: estilos das páginas.
- Imagens PNG na raiz: logotipo e fotografias das receitas.

## Escopo

O formulário aponta para `action="#"`, sem processamento de cadastro no servidor implementado nas páginas. O site é uma demonstração de interface.
